Optimal aim — where to set the glove (catcher's view)

The glove marks where to set the target so each pitch gets its best result once the pitcher's real misses are applied. Every intersquad and game pitch is read as a miss from a middle-middle target (bullpens and game 0-2 pitches are ignored). Run values are measured from 1.84M 2026 D1 pitches for each pitch type, pitcher hand, batter hand and count: how often hitters swing, miss, take a called strike, get hit, and what contact is worth at every spot. Each pitch is then adjusted for his Stuff+, estimated from all his TrackMan outings with a rebuild of the main site's grades. Batter hand and count change the run values; his misses are pooled across them because TrackMan's report does not tie a location to a specific pitch. Throws is read from TrackMan — change it here if it is wrong.
